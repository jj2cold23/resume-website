# Juwan Johnson Portfolio PWA

Personal portfolio Progressive Web App for Assignment 01.

## Features
- Responsive portfolio
- Work experience, technical skills, projects, and hobbies
- Web app manifest
- Service worker and offline caching
- Installable PWA support
- Online/offline status

## PWA Explanation
The manifest tells the browser how the installed application should appear, including its name, icon, theme, and standalone display mode. The service worker caches important application files so the site can continue loading when offline.

## Development Challenges
- Service workers need localhost or HTTPS rather than opening the HTML file directly.
- Browsers may cache older service workers during development.
- PWA icons and manifest paths have to be correct for installation.
- Install prompts depend on browser support and installability requirements.
